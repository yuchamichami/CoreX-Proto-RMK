# 開発用ファイル

[ビルド手順](../docs/BUILDING.md) · [開発資料](../docs/development.md) · [利用ガイド](../README.md)

このフォルダーで `./build.sh` と `./tools/test.sh` を実行します。出力先は `build/` です。

- `source/`：左右のファームウェアとRMKのソース
- `tools/`：ビルド・検査・画像生成のツール
- `keymaps/`：初期配列と参照元
- `firmware/`：同梱UF2、バージョン情報、チェックサム

同梱ファームと利用推奨版が異なる場合は、[開発資料](../docs/development.md#ソースと配布物)で確認してください。
