# 左右がつながらないとき

左右の電源をONにしても接続できない場合は、[ペアリング情報をリセットする手順](pairing.md#上記の手順でうまくいかない場合)を試します。右の操作後は間を空けず、左を操作してください。

## 右からも文字を入力できない

- データ通信できるUSBケーブルで、右をPCにつなぎます。
- PCにUSBドライブが表示されている場合は、右のRESETボタンを1回押します。
- 別のBluetooth接続先へ文字が入力されている場合は、右の接続キーを押しながらPを短く押して離し、USBへ切り替えます。

## 右の操作で反応がない

接続キーを先に押し、そのままHも5秒以上押し続けます。途中でどちらかを離したり、ほかのキーやエンコーダを操作したりしないでください。

キー配列を変更した方は、下の「キー配列を変えていて操作できない場合」を参照してください。

## 左の操作で反応がない

左の充電と電源を確認します。まだ左を書き換えていない場合は、[左側の書き込み](flashing.md#純正-cornix-左を初めて使う)を済ませます。右だけをUSB接続して左から文字が入力できるなら、すでに接続できています。

RESETボタンを押すだけでは、以前の相手の登録は消えません。[ペアリング情報をリセットする手順](pairing.md#上記の手順でうまくいかない場合)を行ってください。右のファームを書き直す必要はありません。

## キー配列を変えていて操作できない場合

左がつながらなくても、右のUSB接続だけで準備できます。

1. 右をUSB接続し、Vialで **`Cornix TB`** を選びます（アプリでは **`CoreX Cornix TB`** と表示されます）。
2. **File → Save current layout** で今の配列を保存します。
3. **Layer 0** の右のHなど、実際に押せる右側のキーを選びます。現在の割り当てを控えておきます。
4. **User** タブの **「左右登録 リセット」**（`Reset split pairing (hold 5s)`）を割り当てます。「PC登録 解除」とは別の項目です。
5. 割り当てたキーだけを5秒以上押し続けて離します。接続キーとの同時押しは不要です。
6. すぐに接続手順の[「2. 左のペアリング情報をリセットする」](pairing.md#2-左のペアリング情報をリセットする)を行います。接続を確認できたら、Vialでキーを元の割り当てに戻します。

## 解決しない場合

[配布・購入時の連絡先、または不具合報告](usage.md#解決しない場合)へ、次の3点をお知らせください。

- 右から文字を入力できるか。
- 右・左それぞれの操作で、ランプがどう光ったか。
- 左に書き込んだファイル名。
