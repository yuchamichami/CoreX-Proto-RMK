書き込み済みのセットを使い始めるときは、[使い方](usage.md)を参照してください。

## ファイル

- **右：coreX＋PAW3222、v0.9.2**
  [coreX-Right-Central-PAW3222-RMK-v0.9.2.uf2](../firmware/coreX-Right-Central-PAW3222-RMK-v0.9.2.uf2)
- **左：純正 Cornix、v0.9.0**
  [coreX-Cornix-StockLeft-Peripheral-RMK-v0.9.0.uf2](../firmware/coreX-Cornix-StockLeft-Peripheral-RMK-v0.9.0.uf2)

GitHub のファイルページでは **Download raw file** で保存します。右 v0.9.2 と左 v0.9.0 を組み合わせて使うため、左右のバージョンは異なります。

**左右の UF2 は入れ替えないでください。純正 Cornix 右用のファームも、coreX 右には使えません。**

この手順は、確認済みのブートローダーが入った基板を対象にしています。RESET を素早く2回押して USB ドライブが表示される基板は、UF2 をコピーして更新できます。SWD 書き込み器は不要です。未書き込みのマイコンへの初回導入は、別の手順が必要です。

## 書き込み前の保存

Vial で **File → Save current layout** を選び、現在の配列を `.vil` ファイルに保存します。

- **coreX を更新する場合：** 右側を USB 接続します。左右のキー配列をまとめて保存できます。
- **純正 Cornix 左を初めて書き換える場合：** 純正ファームが入った左側を USB 接続します。純正用の `.vil` を保存し、元のファームのバージョンも控えます。

coreX 用と純正 Cornix 用でファイル名を分けてください。`.vil` に保存されるのはキー配列などの設定で、ファーム本体や Bluetooth の登録は含まれません。

## ファームウェアを書き込む

**PC には、書き込む側だけを接続してください。** ドライブ名だけでは左右を区別できません。

1. 書き込む側を、データ通信できる USB ケーブルで PC に接続します。
2. 基板の **RESET ボタンを素早く2回**押します。
3. 表示された USB ドライブに、その側の `.uf2` をコピーします。ドライブ名は `NO NAME`、`NRF52BOOT`、`Cornix` など、個体によって異なります。
4. コピー後に基板が自動で再起動し、ドライブが消えます。通常起動まで数秒待ちます。

再起動時に、OS が「ディスクが正しく取り出されませんでした」などと表示することがあります。表示の有無だけで判断せず、書き込み後のキー入力と Vial の認識を確認してください。

## coreX を v0.9.2 に更新する

左に付属の v0.9.0 が入っていれば、**右だけ**を書き換えます。

1. Vial で現在の配列を保存します。
2. 右に `coreX-Right-Central-PAW3222-RMK-v0.9.2.uf2` を、[上の手順](#ファームウェアを書き込む)でコピーします。
3. 再起動後、右を USB 接続した状態で動作を確認します。

確認する項目は次の3つです。

- Vial の機器一覧に `coreX prototype coreX Pair RMK` が表示される。
- 左右の文字キー、ボール、スクロールが動く。
- キーの割り当てと感度・Scroll・AML の設定が残っている。

右 v0.9.0／v0.9.1 からの更新では、配列・感度・AML・接続情報を引き継ぎます。更新前に保存した `.vil` も保管してください。

## 純正 Cornix 左を初めて使う

1. 純正左の `.vil` を保存します。
2. [書き込み手順](#ファームウェアを書き込む)に沿って、左に `coreX-Cornix-StockLeft-Peripheral-RMK-v0.9.0.uf2` を書き込みます。
3. 右に `coreX-Right-Central-PAW3222-RMK-v0.9.2.uf2` を書き込みます。左右は1台ずつ接続し、[書き込み手順](#ファームウェアを書き込む)を繰り返します。
4. 左右の電源を ON にし、右を PC に USB 接続します。未登録の左右は自動で接続します。
5. 左右のキー、ボール、スクロールを試します。Bluetooth で使う場合は、続けて[PC に登録](usage.md#pc-と-bluetooth-接続する)します。

書き換えた左は、キー入力を右へ送る役になります。左を USB 接続すると `coreX Left Link` と表示されることがありますが、キー入力と Vial の設定には右を接続してください。

別の左右ペアの登録が残っていると、自動で接続しない場合があります。まず左右それぞれのファームを確認してください。通常の更新では登録を消す必要はありません。接続できない場合も、全設定の消去やブートローダーの更新を先に行わないでください。

## 純正 Cornix 左へ戻す

メーカーの左用 UF2 を書き込むと、純正ファームへ戻せます。復元後は元の純正 Cornix 右と組み合わせます。coreX 右との組み合わせでは使えなくなります。

1. [メーカーのファーム配布ページ](https://docs.channel.io/jezailfunderjp/ja/articles/Cornix-%E3%83%95%E3%82%A1%E3%83%BC%E3%83%A0%E3%82%A6%E3%82%A7%E3%82%A2-bf1534b6)で対象モデル、元のバージョン、更新履歴を確認し、純正ファームを取得します。
2. **純正左だけ**を PC に USB 接続し、RESET を素早く2回押します。
3. メーカー配布物の **`cornix-left.uf2`** を、そのドライブにコピーします。
4. 再起動後、Vial で Cornix を選び、保存しておいた**純正用**の `.vil` を読み込みます。
5. 純正右との接続と PC の Bluetooth 登録を、[メーカーの更新・再ペアリング手順](https://docs.channel.io/jezailfunderjp/ja/articles/Cornix-%E6%97%A5%E6%9C%AC%E8%AA%9E%E3%83%9E%E3%83%8B%E3%83%A5%E3%82%A2%E3%83%AB-c1160246)に沿って行います。メーカーは、純正の左右を同じバージョンに更新する手順を案内しています。

2026-10-08 に確認した公式配布ページには、v1.13 の不具合に関する追記がありました。ダウンロード前に配布ページの案内を確認してください。公式ファイルは[メーカー GitHub](https://github.com/jezailfunder/cornix-lp)でも案内されています。

**公式の `cornix-right.uf2` を coreX 右へ書き込まないでください。** coreX 右は純正右とは別の基板です。coreX 右を以前の版へ戻す場合は、その基板用に保存した UF2 を使います。

## 書き込み範囲

付属の UF2 はアプリ更新用です。全消去やブートローダーの上書きは行いません。アプリと設定の保存領域、ソースから作り直すときの注意点は [BUILDING.md](../BUILDING.md)を参照してください。
