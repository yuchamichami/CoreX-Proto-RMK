# 書き込み・更新・純正への復元

**書き込み済みの coreX を受け取った場合、このページの操作は不要です。** まずは[使い方](usage.md)で動作を確認してください。

## ファイルを選ぶ

| 書き込む基板 | 使うファイル |
| --- | --- |
| **右：coreX A13＋PAW3222** | [`coreX-A13-Right-Central-PAW3222-RMK-v0.9.2.uf2`](../firmware/coreX-A13-Right-Central-PAW3222-RMK-v0.9.2.uf2) |
| **左：純正 Cornix** | [`coreX-Cornix-StockLeft-Peripheral-RMK-v0.9.0.uf2`](../firmware/coreX-Cornix-StockLeft-Peripheral-RMK-v0.9.0.uf2) |

左右でバージョンが違うのは正常です。左 v0.9.0 は右 v0.9.2 と組み合わせるためのファームです。**左右の UF2 は入れ替えないでください。純正 Cornix 右用のファームも、coreX A13 右には使えません。**

対象は、このプロジェクトで確認したブートローダー入りの基板です。すでに RESET 2回で USB ドライブが出る基板なら、SWD 書き込み器は使いません。未書き込みの裸のマイコンへ初めて導入する手順は、このページの対象外です。

## 更新前に保存する

Vial で現在の配列を開き、**File → Save current layout** で `.vil` を保存します。

- coreX の更新：**右**を USB 接続して保存します。左右のキー配列をまとめて保存できます。
- 純正 Cornix 左を初めて書き換える：まだ純正ファームの状態で**左**を USB 接続し、純正用の `.vil` を保存します。元のファームのバージョンも控えておきます。

`.vil` はキー配列などの設定ファイルで、ファーム本体や Bluetooth の登録を丸ごと保存するものではありません。純正用と coreX 用でファイル名を分けておきます。

## UF2 をコピーする

**PC には、書き込む側を1台ずつ接続してください。** ドライブ名だけでは左右を区別できません。

1. 書き込む側を、データ通信できる USB ケーブルで PC へ接続します。
2. その基板の物理 **RESET を素早く2回**押します。
3. USB ドライブが表示されたら、対象に合った上表の `.uf2` をコピーします。名前は `NO NAME`、`NRF52BOOT`、`Cornix` など、ブートローダーや個体によって異なります。
4. コピー後に基板が自動再起動し、ドライブが消えます。通常入力へ戻るまで数秒待ちます。

自動再起動時に OS が「ディスクが正しく取り出されませんでした」などを表示する場合があります。**エラー表示の有無だけで成功・失敗を決めず、再起動後の入力と Vial の認識で確認**してください。

右エンコーダの押し込みや Fn キーは、書き込みモードへ入るために必須ではありません。物理 RESET を使えます。

### 今の coreX を v0.9.2 へ更新する場合

すでに左へ付属の Peripheral v0.9.0 が入っていれば、**右だけ**を書き換えます。v0.9.0／v0.9.1 からの右更新では、保存形式を維持しており、配列・感度・AML・接続情報を引き継ぎます。それでも更新前の `.vil` 保存は残しておいてください。

書き込み後は、右を通常モードで USB 接続し、次を確認します。

- Vial の機器一覧に `coreX prototype coreX Pair RMK` が表示される。
- 左右の文字キー、ボール、スクロールが動く。
- 感度・Scroll・AML と、変更していたキーの割り当てが残っている。

### 純正 Cornix 左と初めて組み合わせる場合

1. 純正左の `.vil` を保存します。
2. 左に **StockLeft-Peripheral v0.9.0** を書き込みます。
3. 右に **Right-Central-PAW3222 v0.9.2** を書き込みます。
4. 左右とも電源を ON にし、右を PC へ USB 接続します。未登録の左右は自動でペアリングします。
5. 左右のキーを試します。Bluetooth で使う場合は、次に[PC との登録](usage.md#pc-と-bluetooth-接続する)を行います。

左は書き換え後、PC 用キーボードではなく右へキー入力を送る役になります。左を USB 接続すると `coreX Left Link` として見えても、Vial やキー入力の接続先は右です。

既存の別ペアとの登録が残っている場合は、そのまま自動ペアリングしないことがあります。通常更新で登録を消す必要はありません。全設定の消去やブートローダー更新を先に試さず、どちら側がどのファームか確認してください。

## 純正 Cornix 左へ戻す

**純正左は、メーカーの左用 UF2 を入れ直して戻せます。** coreX 右との組み合わせは使えなくなるので、元の純正右と組み合わせて使うための手順です。

1. [メーカーのファーム配布ページ](https://docs.channel.io/jezailfunderjp/ja/articles/Cornix-%E3%83%95%E3%82%A1%E3%83%BC%E3%83%A0%E3%82%A6%E3%82%A7%E3%82%A2-bf1534b6)で、対象モデルと元の版・更新履歴を確認し、純正のファームを取得します。
2. **純正左だけ**を PC へ USB 接続し、RESET を素早く2回押します。
3. メーカー配布物の **`cornix-left.uf2`** を、そのドライブへコピーします。
4. 再起動後、Vial で Cornix を選び、保存しておいた**純正用**の `.vil` を読み込みます。
5. 純正右との接続や PC の Bluetooth 登録は、[メーカーの更新・再ペアリング手順](https://docs.channel.io/jezailfunderjp/ja/articles/Cornix-%E6%97%A5%E6%9C%AC%E8%AA%9E%E3%83%9E%E3%83%8B%E3%83%A5%E3%82%A2%E3%83%AB-c1160246)に従います。メーカーは純正左右を同じ版へ更新する流れを案内しています。

2026-10-08 確認時点の公式配布ページには、v1.13 の不具合に関する追記があります。「数字が最大の版」を自動的に選ばず、配布ページの案内を確認してください。公式ファイルは[メーカー GitHub](https://github.com/jezailfunder/cornix-lp)でも案内されています。

**公式の `cornix-right.uf2` を coreX A13 右へ書き込まないでください。** coreX 右は純正右とは別の基板です。右を戻したい場合は、その基板用に保存した coreX の UF2 を使います。

<details>
<summary>開発者向け：書き換え範囲と保存領域</summary>

| 対象 | アプリ開始 | この構成の設定領域 | ブートローダー開始 |
| --- | --- | --- | --- |
| coreX A13 右 | `0x26000` | `0xB0000..0xD0000` | `0xF4000` |
| 確認済みの純正 Cornix 左 | `0x1000` | `0xC0000..0xE0000` | `0xF4000` |

付属の UF2 はアプリ更新用です。全消去やブートローダーの上書きは行いません。右の `0x26000` と左の `0x1000` は同じ nRF52840 でも異なるため、型番が同じことだけで互換と判断できません。

左の coreX 設定領域は、確認した純正設定領域 `0xA0000..0xC0000` と重ならない位置にしています。ただし、純正ファームへ戻した際の設定読み出しまで保証するものではありません。純正 `.vil` の別保存を使ってください。

右 v0.9.0～v0.9.2 の設定形式識別値は `0xA805CEFB` です。ソースから作り直す場合も、リポジトリのビルド手順で付属の metadata wrapper を使います。依存 RMK のコミット情報やコンパイル機能を不用意に変更すると、設定形式が変わり初期化される場合があります。

</details>
