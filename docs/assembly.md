# CoreX 組み立てガイド

写真の出荷品では、基板裏にある2つのケーブル用コネクターのうち、**ボールから遠い側**を使います。右のファームは書き込み済みなので、そのまま動作確認できます。配布中の「ボールに近い側」用の右ファームで上書きしないでください。

純正Cornixの右側を、CoreXの交換基板とトラックボールに組み替えます。左側は分解せず、最後にファームウェアを書き換えます。

[ファームのダウンロード](../README.md#1-ファームをダウンロードする) · [書き込み手順](flashing.md) · [組み立て後の使い方](usage.md)

## 用意するもの

- 純正Cornix
- CoreXの交換基板
- センサー基板を組み込んだトラックボールケース、FPCケーブル、ボール、固定用ネジ2本
- ネジに合うサイズのプラスドライバーと星型ドライバー
- キーキャッププラー、スイッチプラー、ピンセット
- 外したネジを入れる小皿など
- PCと、データ通信できるUSBケーブル

純正のケース、トッププレート、フォーム、バッテリー、スイッチ、キーキャップ、ネジは再利用します。外した部品はまとめて保管してください。

**特に傷めやすいのは、バッテリーコネクターとアルミケースのネジ穴です。** コネクターは配線を引っ張らずに外し、ネジは強く締め込まないでください。バッテリーコネクターを破損した場合の案内は[ページ末尾](#バッテリーコネクターを破損した場合)にあります。

## 1. Cornix右側を分解する

配列を変更している場合は、作業前にVialの **File → Save current layout** で保存しておきます。

1. 電源をOFFにし、USBケーブルを抜きます。
2. 右側のキーキャップ、スイッチ、エンコーダのノブを取り外します。
3. ドライバーを使い分けて、ケースのネジをすべて外します。**1か所はシールに隠れているので、シールを剥がして外してください。**
4. 先にマイコンカバーを持ち上げ、その後トッププレートを持ち上げて外します。

すっと持ち上がらない場合は、ネジが残っていないか確認してください。無理にこじ開けず、基板につながっているバッテリーの配線にも余裕を持たせます。

## 2. バッテリーを外し、純正基板を保管する

1. バッテリーにつながるコネクターを確認します。
2. ピンセットなどで、**ケーブル側のコネクターの樹脂部分**をつかみ、ゆっくり抜きます。配線を引っ張ったり、基板側のソケットをこじったりしないでください。ピンセットを金属端子に触れさせないようにします。
3. 純正基板を取り出します。CoreXの交換基板を袋から出し、その袋に純正基板を入れて保管します。

純正基板は裸のまま置かないでください。他の物に当たると、小さな部品が外れたり傷ついたりすることがあります。

## 3. フォームとトッププレートを仮固定する

1. CoreXの交換基板に、トッププレート下のフォームを重ねます。
2. その上にトッププレートを重ね、スイッチの穴を合わせます。
3. 四隅のスイッチを先に取り付けて、基板・フォーム・トッププレートを仮固定します。フォームがずれたり、折れ込んだりしていないか確認します。

## 4. トラックボールのケーブルを接続する

この作業中はUSBとバッテリーを外したままにします。FPCは、トラックボールケースから出ている薄い平たいケーブルです。

1. FPCケーブルを、トッププレートの側面から基板の穴へ通し、基板の裏側へ出します。ケースをケーブルでぶら下げないよう、手で支えてください。
2. 基板裏の2つのコネクターのうち、**ボールから遠い側**を確認します。
3. 茶色のストッパーを、ピンセットなどでそっと上げます。コネクター本体を持ち上げないようにしてください。
4. コネクターのある基板面を上に向け、**FPCの金属端子が露出している面を下（基板側）に向けて**、まっすぐ奥まで差し込みます。
5. ストッパーを下げてケーブルを固定します。斜めに入っていたり、途中までしか入っていない状態で閉じないでください。

ストッパーは小さく壊れやすいため、閉じたままケーブルを押し込んだり、強く引き抜いたりしないでください。

## 5. USBでトラックボールの動作を確認する

トラックボールケースをネジで固定する前に確認します。基板は金属に触れない場所へ置き、バッテリーはまだ接続しません。

1. 右基板をPCにUSB接続します。
2. 出荷品は右のファームを書き込み済みです。USB接続後、数秒待ちます。ボールに近い側のコネクターを使い、まだ書き込んでいない場合のみ、[対応する右ファームの書き込み手順](flashing.md)へ進んでください。
3. 起動したらボールをケースに入れて回し、PCのポインターが動くことを確認します。
4. 動作を確認できたら、USBケーブルを抜きます。

<p>
  <a href="images/assembly/IMG_3802_clean.jpg"><img src="images/assembly/IMG_3802_clean.jpg" width="640" alt="ケースを閉じる前に、USB接続でボールの動作を確認する"></a>
</p>

ケースを閉じる前に、USB接続でボールの動作を確認する

動かない場合は、下の項目を確認してから先へ進みます。**ケーブルやセンサー基板を触る前に、USBを抜いてください。**

### トラックボールが動かない場合

- **交換基板側のFPC接続：** 端子の向き、差し込みの深さ、ストッパーが閉じているかを確認します。
- **センサー基板の位置：** センサー基板はケースに入れた状態で出荷します。ケーブルを強く引くと位置がずれることがあるため、浮いている場合は基板本体をそっと押して、ケースの奥まで戻します。
- **センサー基板側のFPC接続：** ケーブルが抜けていたら、小さなコネクターのストッパーを上げ、元の向きで差し込み直します。奥まで入れたらストッパーを下げます。元の向きが分からない場合は、無理に差し込まず、配布・購入時の連絡先へご連絡ください。

センサー基板とコネクターはとても小さいので、ケーブルで引っ張らず、基板本体を支えて扱ってください。確認後にUSBをつなぎ直し、もう一度ボールを回します。

## 6. ケースを固定し、バッテリーを接続する

1. USBを抜いた状態で、トラックボールケースを**基板の裏からネジ2本**で固定します。ケーブルを挟まず、無理に引っ張られない位置に収めます。
2. 一度USBをつなぎ、固定後もボールが動くことを確認します。確認したらUSBを抜きます。
3. バッテリーのコネクターをCoreX基板に差し込みます。純正Cornixと同じ極性です。元と同じ向きで、無理な力をかけずに接続してください。
4. USBをつなぎ、充電中に基板裏の赤い充電LEDが点灯することを確認します。満充電などで充電していないときは、点灯しない場合があります。
5. 確認が済んだら、USBを抜き、電源をOFFにしてからケースへ戻します。

## 7. アルミケースに戻す

1. スライドスイッチカバーの内側のくぼみと、基板のスライドスイッチの位置を合わせます。スイッチは壊れやすいので、ずれたまま基板を押し込まないでください。
2. バッテリーの配線を収めながら、仮固定した基板・フォーム・トッププレートをケースにセットします。配線が浮いていたら、挟み込まない位置へそっと押さえて収めます。
3. 基板やプレートに浮きがないことを確認し、マイコンカバーを戻して上からネジ留めします。
4. 残りのスイッチとキーキャップを取り付けます。

**浮いた基板を、ネジの力で押し下げないでください。** スイッチカバー、バッテリーの配線、FPCケーブルの位置を先に確認します。

ネジは部品が動かなくなる程度に締め、強く締め込まないでください。アルミケースのネジ穴を傷めると、そのままでは固定できなくなります。

## 8. 左側を書き換え、左右を接続する

1. [純正Cornix左への書き込み手順](flashing.md#純正-cornix-左を初めて使う)に沿って、純正の設定を保存してから左用ファームを書き込みます。出荷品の右は書き込み済みなので、書き直す必要はありません。
2. [左右を接続する手順](pairing.md)に沿って、左右の電源をONにします。右だけをUSB接続した状態で、左右どちらからも文字を入力できれば完了です。
3. Bluetoothで使う場合は、続けて[PCとのペアリング](../README.md#4-pcとbluetoothでペアリングする)を進めます。
4. [操作確認](../README.md#5-操作を確認する)に沿って、キー、ボール、クリック、スクロールを試します。

これで組み立ては完了です。おつかれさまでした。

## バッテリーコネクターを破損した場合

バッテリーコネクターは国内での入手が難しい部品です。ちぎれたり破損した場合は、作業を止めて、配布・購入時の連絡先へご連絡ください。交換品を用意します。
