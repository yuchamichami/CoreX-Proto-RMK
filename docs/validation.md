# 検証状況

対象は右v0.9.2・左v0.9.0です。

## 実機で確認したこと

- 右のキー入力、PAW3222のカーソル移動とスクロール、Vialの認識。
- 感度・Scroll・AML設定の保存。AMLのON／OFFはv0.9.1で確認しています。
- 右をv0.9.2へ更新した前後で、280キー分の割り当て、左右エンコーダ、Vial設定が一致すること。
- 左v0.9.0との無線キー入力。左右接続は前版で確認済みで、今回の右だけの更新後には再試験していません。

## 配布ファイルで確認したこと

開発PCのパスがバイナリに残らないよう、同じアプリのソースからUF2を再ビルドしています。**再ビルド後のUF2そのものは、実機へ書き込んで再確認していません。**

配布ファイルについては、次を確認しました。

- 左右ともビルドが完了すること。
- UF2の書き込み範囲が、ブートローダーと設定領域に重ならないこと。
- 設定の保存形式が `0xA805CEFB` のままであること。
- UF2に開発者のローカルパスや、既知の個体識別情報が含まれないこと。
- ホスト上のテスト11件が成功すること。

[配布ファイルのSHA-256](../firmware/SHA256SUMS)と[ビルド情報](../firmware/manifest.json)を同梱しています。別のフォルダーや環境でビルドすると、同じソースでもハッシュが変わる場合があります。検査方法は[ビルド手順](../BUILDING.md)を参照してください。

## 未確認・未対応

純正Cornixの無線ドングルとの接続と電池持ちは未確認です。接続・電池状態を示す純正のLED表示には対応していません。v0.9.2にはトラックポイントとタッチパッドの処理を含めていません。
