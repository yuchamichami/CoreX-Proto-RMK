# 検証状況

対象は右v0.9.4・左v0.9.0です。

## v0.9.4

右側の表示名を `Cornix TB`、製品の表記を `CoreX` に変更しています。キー配列とトラックボールの処理は v0.9.3 から変更していません。

実機で次を確認しました。

- 右への UF2 書き込みと、USB での通常起動。
- USB の製品名 `Cornix TB`・メーカー名 `CoreX`、Vial 定義名 `CoreX PAW3222`。
- 更新前後の Vial 保存データの一致。392セル、エンコーダ28方向、マクロなどの設定が保持されました。

**更新後のキー・ボール操作と Bluetooth の再接続は未確認です。** Bluetooth の表示名も `Cornix TB` を使うことはソースで確認していますが、実際に送信される名前は測定していません。

## v0.9.3 の初期配列

右への UF2 書き込み、USB での通常起動、初期配列の適用と読み戻しを確認しました。392セルとエンコーダ28方向が配布する初期配列と一致しています。新しいキー位置、エンコーダの向きと Bluetooth 操作について、手で操作しての確認は完了していません。

初期配列は、2026-10-09に取得した[メーカー配布の初期キーマップ](https://docs.channel.io/jezailfunderjp/ja/articles/Cornix-%E6%97%A5%E6%9C%AC%E8%AA%9E%E3%83%9E%E3%83%8B%E3%83%A5%E3%82%A2%E3%83%AB-c1160246)を基にしています。通常キー・数字記号・エンコーダを純正の位置に対応させ、トラックボール用の操作と設定欄を加えています。

実機を使わない検査では、次を確認しました。

- 右 v0.9.3 のビルドが成功し、配布ファイルと再ビルド結果が一致すること。左 v0.9.0 のファイルは変更していません。
- UF2 がブートローダーと設定領域に重ならず、開発PCのローカルパスを含まないこと。
- 設定の保存形式が `0xA805CEFB` のままであること。
- 既存の Rust テスト11件と、初期配列の Python テスト9件が通ること。初期配列ファイルも生成結果と一致しています。
- Vial の仮想キーボードで初期配列ファイルを読み込み、再保存した392セルとエンコーダ28方向が元の配列と一致すること。既存マクロも保持されました。

このオフライン検査には、実機でのキー入力やBluetooth接続、UF2更新後の設定読み出しは含みません。

## 旧版で実機確認したこと

以下はv0.9.2以前の確認結果です。v0.9.4 の動作確認を示すものではありません。

- 右のキー入力、PAW3222のカーソル移動とスクロール、Vialの認識。
- 感度・Scroll・AML設定の保存。AMLのON／OFFはv0.9.1で確認しています。
- 右をv0.9.2へ更新した前後で、280キー分の割り当て、左右エンコーダ、Vial設定が一致すること。
- 左v0.9.0との無線キー入力。左右接続はv0.9.2への更新前に確認しています。

## 配布ファイル

[配布ファイルのSHA-256](../firmware/SHA256SUMS)と[ビルド情報](../firmware/manifest.json)を同梱しています。別のフォルダーや環境でビルドすると、同じソースでもハッシュが変わる場合があります。検査方法は[ビルド手順](../BUILDING.md)を参照してください。

## 未確認・未対応

純正Cornixの無線ドングルとの接続と電池持ちは未確認です。接続・電池状態を示す純正のLED表示には対応していません。v0.9.4にはトラックポイントとタッチパッドの処理を含めていません。
